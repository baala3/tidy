# Safety notes

Tidy deletes files, so the times it got that wrong are worth writing down.
This log has one entry for each time Tidy removed, or could have removed, something it should not have.
Each entry says what happened, who was affected, what changed, and which test now catches it.

Entries are added only when something real happens.
If you hit something that belongs here, [SECURITY.md](../SECURITY.md) says how to report it.

No incidents so far.
