# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Be kind, assume good intent, and keep discussion about the work.

Report unacceptable behavior privately to the maintainer, [@baala3](https://github.com/baala3), using the contact details on their profile.
Reports are kept confidential, and the maintainer may remove comments or block people who break these rules.
