Safety

Tidy only clears what is listed on this page. This page is generated from Tidy 0.5.0's own rules, so it always matches what the app does.

Every path is checked again at the moment it is moved, and goes to the Recycle Bin. Anything behind a link or junction is skipped. If the Recycle Bin is off for a drive, or an item is too big for it, Tidy leaves it alone rather than delete it for good.

WSL & Docker

The disk images of the WSL 2 distros WSL lists for you, and Docker Desktop's own disks in its folder; no other virtual disk is offered, and none behind a link. Compacting stops Docker Desktop and shuts WSL down first, then gives back the blocks the disk no longer uses. Nothing inside a disk is changed or removed.

Duplicates

Files over 1 MB in Documents, Desktop, Downloads, Videos, Music and Pictures whose contents match byte for byte, outside project and app folders. A hard link is one file under two names, so it is never listed as a duplicate. Nothing is selected for you, one copy of every file always stays, and right before a copy moves it is compared again with the one that stays.

OneDrive

Files over 1 MB in your OneDrive folders that are fully synced and also kept on this PC. Free Up Space marks them online-only, as File Explorer's "Free up space" does, and OneDrive then removes the local copy. Nothing is deleted: each file stays in OneDrive and in File Explorer. Files still syncing, files set to always stay on this device, Personal Vault, and anything behind a link are never offered, and each file is checked again right before it changes.

Installers

Installer files in the same folders, offered only for apps that are installed: an .msi by its ProductCode, an .msix or .appx by its package name, and an .exe by product name once it shows it is an installer (setup in its name or details, or the mark of an installer framework). Installers for anything else are never listed. Nothing is selected for you, and installers newer than the installed app are Check First.

Everything that starts when you sign in: Run keys, the Startup folders, Store apps' startup tasks, and Task Scheduler tasks that run at sign-in (except Windows' own). Turning one off flips the switch Task Manager, Settings or Task Scheduler already has, so nothing is deleted and it can be turned back on there. Entries that start for everyone on the PC need administrator permission. Tidy shows only measured numbers: what each one's programs use now, and what Windows recorded them using at your last sign-in.
